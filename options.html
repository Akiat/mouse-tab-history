To change one, click it, hold any modifier keys and press a mouse side button. If you choose a side button with no modifier, it stops going back a page.

Mouse shortcuts only work on web pages

Browsers don't show extensions the clicks made outside a web page. Your mouse shortcut does nothing while the pointer is on the tab strip, the address bar or the bookmarks bar, or on browser pages like Settings, Extensions, the New Tab page and the Web Store.

Use a keyboard shortcut in those places.

These work anywhere in the browser. Extensions can't change their own keyboard shortcuts, so you set them on your browser's shortcuts page.

How the history works

  • Each window keeps its own history.
  • Closed tabs are skipped.
  • If you go back and then open a different tab, the forward tabs are dropped, like page history.

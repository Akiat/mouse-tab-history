# Privacy policy

Mouse Tab History doesn't send or sell any data. It makes no network requests.

## What it reads

Each time you release a mouse button on a web page, the extension checks which button it was and which modifier keys you held, to detect your mouse shortcut. This happens on your device and isn't recorded.

## What it stores

It keeps two things in your browser:

- The internal IDs of the tabs you viewed, with no URLs or titles. The browser clears these when it closes.
- Your mouse shortcuts, in the browser's sync storage. They follow your browser account if you have sync turned on.

## Why it asks for access to all websites

The extension has to run in each page to detect your mouse shortcut, because browsers have no other way to report side button clicks to an extension. That script doesn't read the page.

The source code is public, so you can check all of this yourself.
